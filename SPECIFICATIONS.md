# 📊 Extasis Marimba — Technical Specifications

### Architecture & Audio Specifications
* **Type:** Virtual Synthesizer / Instrument Plugin
* **DSP Engine:** 64-bit Floating-Point Hybrid Modal Physical Modeling & Inharmonic FM Synthesis
* **Polyphony:** 16-Voice Dynamic Polyphony with Oldest-Voice Stealing
* **Sampling Rate Support:** 44.1 kHz, 48.0 kHz, 88.2 kHz, 96.0 kHz, 192.0 kHz
* **Internal Resolution:** 32/64-bit Floating Point Audio Processing
* **Latency:** 0 Samples (Zero-latency direct physical rendering)
* **MIDI Compatibility:** MIDI Note On/Off (0-127), Velocity (0-127), All Notes Off, CC Automation

### GUI & Visualizer
* **Interface Resolution:** 920 x 520 px (Retina & High-DPI Optimized)
* **Visualizer Frame Rate:** 30 Hz Smooth Rendering
* **Visualizer Features:** Real-Time Oscilloscope with zero-crossing sync + 5 Tuned Modal Resonator Amplitude Bars + Monospaced Parameter Telemetry

* **Windows:** Windows 10 / 11 (64-bit)
